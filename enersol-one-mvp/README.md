# Enersol One MVP

MVP target:
- Projects management
- Documents management
- Outlook import for Order Acknowledgements
- Dashboard with operational alerts

## Modules

- `apps/web`: frontend dashboard and project UI
- `apps/api`: backend API, parsing and matching logic
- `docs`: functional and technical documentation
- `data`: local storage placeholders for project files and documents

## MVP scope

1. Projects
2. Documents
3. Outlook + AI extraction pipeline
4. Dashboard KPIs and alerts

## Next phase (after MVP)

- Full email assistant workflows
- Commands and shipments tracking expansion
- Fine-grained role permissions
- Advanced reporting
